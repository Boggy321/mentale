# Understanding Teen Stress

A PPL30 Healthy Living Action Project website about stress and mental health in teens.

## How to open it

No build step, no install. Double-click `index.html` to open it directly in a browser.

Everything (HTML, CSS, JS, fonts, icons) is local. It works fully offline, with no external requests.

## Presentation Mode

Click the **Presentation mode** button in the header (the monitor icon), or press **P** on any page.

- **→ / ←** step through that page's main sections.
- A counter in the bottom bar shows which step you're on.
- **Esc**, or the Exit button, leaves presentation mode.
- Type enlarges and the nav/footer hide, so each section reads clearly on a projector.

Presentation Mode works per page, it steps through the current page's sections, not across the whole site. Use the regular nav (or arrow keys browser-style page navigation isn't included) to move between pages.

## Other things worth knowing

- **Dark mode**: follows the system preference automatically, or toggle it manually with the sun/moon icon in the header. The choice is remembered per browser.
- **Stress Check-in quiz** (Teen Stress & Social Media page) and **Wellness Tracker** (Warning Signs & What Helps page): nothing typed into either is sent anywhere. The tracker saves to the browser's local storage only, with a Reset button to clear it.
- **Sources page**: every `[source]` marker on the site links to a matching numbered entry there.
